To Deploy this stack in AWS : 
Login to AWS Cloud shell enter "bash <(curl -H 'Cache-Control: no-cache' -s https://raw.githubusercontent.com/Karthiraj1981/open-ipass-oneclick/main/deploy.sh)"

To clean up (Destroy this setup in AWS): 
Login to AWS Cloud shell and Enter "bash <(curl -s https://raw.githubusercontent.com/Karthiraj1981/open-ipass-oneclick/main/delete.sh)"
